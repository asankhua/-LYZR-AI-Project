Executive Summary

Travel Planner is a multi-tenant, real-time group trip orchestrator engineered to eliminate group chat friction. By combining shared ideation boards with autonomous multi-agent synthesis, the app democratizes travel decisions through structured quadratic polling, automatically constructs conflict-free day plans using routing heuristics, and automates multi-currency expense equalization via split-ledger settlement graphs.

03 //

End-to-End User Journey

01

Trip Genesis & Deep Link Provisioning

Host defines destination, tentative dates, and dispatches zero-login magic links with guest role allowances.

02

Collaborative Ideation & Flight Staking

Attendees pin accommodation links and flight itineraries; real-time quadratic voting aggregates consensus.

03

Autonomous Itinerary Generation

Planner Agent sequences activities by geographic clustering, venue operational hours, and commute buffers.

04

Reservation Sync & Calendar Export

Automated confirmation parser binds reservation references and pushes synced iCal/Google Calendar feeds to guests.

05

Unified Ledger & Net-Debt Settlement

Optical Character Recognition (OCR) receipt intake resolves group debt into minimal transaction pairs via Stripe.
